# CMS Editor Guide (Sanity)

This guide is for content editors.

## 1) Where to Edit

- Open your Sanity Studio URL.
- Go to `Structure`.
- Choose a section:
  - Hero
  - About
  - Activities
  - Operating Model
  - Regional Presence
  - Contact
  - Footer

## 2) How to Publish Changes

1. Open a document.
2. Edit fields.
3. Click `Publish` (top right).
4. Refresh `https://pag-global.com` and verify.

If the page still shows old text:

1. Hard refresh browser (`Ctrl + F5`).
2. Purge Cloudflare cache.
3. Confirm document is published, not draft-only.

## 3) Recommended Editing Rules

- Keep headlines concise.
- Keep email/phone values consistent with official contact details.
- Use institutional language.
- Avoid adding temporary placeholder text in production content.

## 4) Image Rules

- Use real infrastructure/technology imagery where requested by brand direction.
- Avoid stock lifestyle photos.
- Keep image quality high and crop-safe for desktop/mobile.

## 5) Common Mistakes

- Editing a draft but not publishing.
- Editing wrong language/section.
- Expecting CMS at `/admin` on website domain (Studio is hosted by Sanity).

## 6) Quick Verification

After each update, verify:

- Navigation works
- Updated section appears correctly
- No layout break on mobile
